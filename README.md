# Enterprise Employee Data Preparation

## Project Overview

This project focuses on cleaning and preprocessing the IBM HR Analytics Employee Attrition dataset using Python and Scikit-learn.

## Dataset Information

- Dataset: IBM HR Analytics
- Original Records: 1,470
- Original Features: 35

## Activities Performed

1. Dataset Import
2. Missing Value Analysis
3. Duplicate Record Handling
4. Outlier Detection using IQR
5. Categorical Encoding
6. Numerical Feature Scaling
7. Derived Feature Creation
8. Preprocessing Pipeline Creation
9. Processed Dataset Export

## Derived Features

- YearsPerCompany
- YearsSinceJoining

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Project Files

- `Enterprise_Employee_Data_Preparation.ipynb` – Complete project notebook and reports.
- `Employee_Attrition_Processed.csv` – Final processed dataset.

## Deliverables

- Clean Dataset
- Data Cleaning Report
- Feature Engineering Report
- Pipeline Documentation
